# ApexMindReads 📚

Digital Guides for Mindset & Everyday Wisdom.

## Tech Stack
- **Frontend**: React 18 + Vite + TailwindCSS + Lucide Icons
- **Backend**: Express + Firebase Admin + Paystack Payment Gateway
- **Deployment**: Vercel Serverless

## Setup & Development
```bash
pnpm install
pnpm dev
```

## Production Build
```bash
pnpm build
```
